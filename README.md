# Vínculo - Protótipo de alta fidelidade

Site institucional e vitrine de recomendações de profissionais de saúde.

## Abrir

Baixe ou clone o repositório e abra index.html no navegador. O protótipo funciona sem instalação e sem conexão com serviços externos.

## Navegação

- Recomendações: pesquisa gratuita por nome e apresentação dos perfis de parceiros (RF01 / T01).
- Planos: pesquisa de planos de participação na vitrine (RF19 / T02).
- Acesso administrativo: autenticação demonstrativa do funcionário (RF02 / T03).
- Funcionários: consultar, incluir, alterar e excluir (RF03-RF06 / T04-T06 e J01).
- Parceiros: consultar, incluir, alterar e excluir (RF07-RF10 / T07-T09 e J02).
- Afiliados: consultar, incluir, alterar e excluir (RF11-RF14 / T10-T12 e J03).
- Planos administrativos: consultar, incluir, alterar e excluir (RF15-RF18 / T13-T15 e J04).

## Dados

Os dados são ilustrativos. As operações ficam guardadas somente no navegador em que o protótipo é usado. O acesso é uma simulação para apresentação, sem autenticação de produção ou banco de dados remoto. Os valores e as condições reais dos planos permanecem em aberto.

## Arquivos de origem

Os arquivos index.html, styles.css e app.js contêm o protótipo.
